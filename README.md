# Saba Abdi — personal website

Static academic and professional portfolio, prepared for https://saba-abdi.github.io/.

## Publish on GitHub Pages

1. Create a public repository on the **Saba-Abdi** account named **saba-abdi.github.io**. If that repository already exists, review its contents before replacing anything.
2. Upload the contents of this folder to the repository root, including `assets/` and `.nojekyll`. Do not upload the ZIP itself.
3. In **Settings → Pages**, choose **Deploy from a branch**, **main**, and **/ (root)**, then save.
4. Wait for deployment to complete and visit https://saba-abdi.github.io/.

GitHub documentation: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Maintain

Edit text in `index.html` and styling in `styles.css`. Replace `assets/Saba-Abdi-CV.pdf` to update the CV download. Update the employment dates if the role changes. No framework, installation, API keys, or build step is required. All website assets are local, and the site requires no JavaScript.

## Content

Professional and academic details are based on the supplied CV. Project repository URLs were extracted from the PDF hyperlinks. Thesis is presented as research, not as a publication. MSc direct admission is presented as an honor, not as enrollment. GRE component scores are not inferred. The downloadable CV is the original supplied PDF.
